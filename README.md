# Vnua Systems

The hub for Vnua Industries: https://adrielvent.github.io/vnua-systems/

One static page (`index.html`), no build step. It lists each Vnua Industries product with what it is,
its real status, and a link: Vnua Connect, Vnua Lock, DatumPane (https://www.adrielv.me) and Vnua Apparel.
Engineering write-ups live in the portfolio repo (AdrielVent/adriel-portfolio); this page only links to it.

The cube is three.js r160 from jsDelivr. It renders only while visible and respects Reduce Motion.
If WebGL or the script fails, the cube is hidden and the rest of the page is unaffected.
